1. What is the initial requirement to start a CrewAI project?
   a) Installing Java Runtime Environment
   b) Using a cloud-based platform
   c) Generating a project folder structure using a command-line interface
   d) Creating a database
   - Correct Answer: c) Generating a project folder structure using a command-line interface

2. What files and folders are included in the default project structure of a CrewAI project?
   a) `setup.py`, `.dockerignore`, `README.md`, `src/my_project`
   b) `.gitignore`, `requirements.txt`, `LICENSE`, `.env`
   c) `.gitignore`, `pyproject.toml`, `README.md`, `src/my_project`
   d) `main.py`, `MANIFEST.in`, `docs/`
   - Correct Answer: c) `.gitignore`, `pyproject.toml`, `README.md`, `src/my_project`

3. Which file is used to manage environment variables in a CrewAI project?
   a) `settings.cfg`
   b) `.env`
   c) `config.ini`
   d) `vars.env`
   - Correct Answer: b) `.env`

4. How does CrewAI facilitate collaborative AI solutions?
   a) By providing single-agent task management systems
   b) By enabling cohesive multi-agent interactions
   c) Through blockchain technology
   d) By integrating with social media platforms
   - Correct Answer: b) By enabling cohesive multi-agent interactions
